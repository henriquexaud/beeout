# M07: Você voltou

| | |
|---|---|
| **Status** | Ideia |
| **Gatilho no app** | Usuário volta depois de dias sem registrar ou depois de uma recaída |
| **Duração** | ~5 s |
| **Loop** | não |
| **Poses e expressões** | Costas (turnaround), "Orgulho disfarçado" |

## Ideia em uma frase

Ele percebe que você voltou, finge indiferença e não consegue esconder que ficou feliz. Nenhuma cobrança.

## Roteiro

| Tempo | O que acontece | Fala / legenda |
|---|---|---|
| 0.0 s | Mamu de costas | |
| 0.5 s | Uma orelha levanta | |
| 1.2 s | Vira devagar (costas → 3/4 → frente) | |
| 2.4 s | Cara de tédio forçada | "Ah. Você." |
| 3.4 s | Escapa um sorriso; ele cobre com a tromba | "…Que bom. Quer dizer, tanto faz. Que bom." |

## Notas de animação

- Depois de uma recaída o tom é acolhedor: zero sermão. Se tiver uma fala extra, que seja "Comigo acontece toda terça."
