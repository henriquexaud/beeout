# M09: Dessa parte eu não entendo

| | |
|---|---|
| **Status** | Ideia |
| **Gatilho no app** | Sinais de que o assunto vai além de um mau hábito (dependência severa, crise) |
| **Duração** | ~4 s |
| **Loop** | não |
| **Poses e expressões** | "Dessa parte eu não entendo" (sem o "?" cômico) |

## Ideia em uma frase

Quando o assunto é sério, o deboche sai de cena. Ele admite o limite e aponta para quem entende.

## Roteiro

| Tempo | O que acontece | Fala / legenda |
|---|---|---|
| 0.0 s | Sem cigarro, sem piada. Postura mais ereta | |
| 0.5 s | Olha direto para a câmera, com sobrancelhas neutras | "Dessa parte eu não entendo." |
| 1.8 s | | "Mas tem gente que entende, e vale conversar com ela." |
| 2.8 s | Aparece o botão/CTA de ajuda | |

## Notas de animação

- É o único motion sem humor. A mudança de tom precisa ser clara: movimento mínimo, sem side-eye.
- Validar com o time os canais de ajuda (ver [produto.md](../../conceito/produto.md#cuidados)).
