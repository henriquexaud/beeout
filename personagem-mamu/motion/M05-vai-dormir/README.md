# M05: Vai dormir

| | |
|---|---|
| **Status** | Ideia |
| **Gatilho no app** | Uso depois da meia-noite |
| **Duração** | ~5 s |
| **Loop** | não |
| **Poses** | 1 (frente) com olho vermelho (a desenhar), 8 (mão na cara), da [folha v2](../../arte/mamu-v2.png) |

## Ideia em uma frase

Às 3h da manhã ele manda você dormir e percebe a própria hipocrisia antes que você aponte.

## Roteiro

| Tempo | O que acontece | Fala / legenda |
|---|---|---|
| 0.0 s | Quarto escuro, olho vermelho, olheira no máximo. Relógio: 3:47 | |
| 0.6 s | Bocejo longo | |
| 1.6 s | | "Vai dormir." |
| 2.6 s | Pausa. Olha para o relógio, depois para a câmera | |
| 3.4 s | | "Eu sei. Eu sei. Não é sobre mim." |

## Notas de animação

- O bocejo pede uma antecipação bem longa, porque é o "lento pra começar" no extremo.
- A piscada aqui é a mais lenta de todas.
