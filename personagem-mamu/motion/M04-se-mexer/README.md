# M04: Você precisa se mexer

| | |
|---|---|
| **Status** | Ideia |
| **Gatilho no app** | Dia sem passos/atividade |
| **Duração** | ~5 s |
| **Loop** | não |
| **Poses** | 1 (frente) + tromba esticada e controle (a desenhar), da [folha v2](../../arte/mamu-v2.png) |

## Ideia em uma frase

Diz que você precisa se movimentar enquanto estica a tromba até o controle, sem levantar.

## Roteiro

| Tempo | O que acontece | Fala / legenda |
|---|---|---|
| 0.0 s | Mamu sentado ou largado | |
| 0.4 s | Discurso motivacional, com a mão na barriga | "Movimento é tudo. O corpo foi feito pra isso." |
| 1.5 s | Enquanto fala, a tromba estica pelo chão, em ondas, até o controle | |
| 3.2 s | Pega o controle. Percebe que você viu | |
| 4.0 s | Larga o controle devagar… e depois puxa de volta | "…Depois do episódio." |

## Notas de animação

- A tromba é a protagonista: movimento ondulado, com a ponta "procurando".
- O corpo fica totalmente parado durante o alcance.
