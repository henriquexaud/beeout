# M08: Orgulho disfarçado

| | |
|---|---|
| **Status** | Ideia |
| **Gatilho no app** | Marco de sequência (3, 7, 30 dias) |
| **Duração** | ~4 s |
| **Loop** | não |
| **Poses** | 6 (acenando) como base; rosto corado (a desenhar), da [folha v2](../../arte/mamu-v2.png) |

## Ideia em uma frase

Ele fica orgulhoso do seu progresso e tenta muito disfarçar.

## Roteiro

| Tempo | O que acontece | Fala / legenda |
|---|---|---|
| 0.0 s | O número do marco aparece | |
| 0.4 s | Olha de lado, coça a cabeça, bochecha corada | "Tá. Foi bom." |
| 1.8 s | | "Não se acostuma." |
| 2.6 s | Acha que a câmera desviou e faz uma comemoração mínima (punho fechado, pulinho de 2 cm) | |
| 3.4 s | Percebe que foi visto e congela | |

## Notas de animação

- A comemoração escondida é a recompensa. Ela precisa ser pequena e muito rápida.
- Nesta tela ele aparece **sem cigarro**: a conquista é do usuário.
