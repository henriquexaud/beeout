# M03: Comida de verdade

| | |
|---|---|
| **Status** | Ideia |
| **Gatilho no app** | Registro de delivery / fast food |
| **Duração** | ~4 s |
| **Loop** | não |
| **Poses** | 1 (frente) + sacola de delivery (a desenhar), da [folha v2](../../arte/mamu-v2.png) |

## Ideia em uma frase

Recomenda comida de verdade e, discretamente, empurra a sacola de delivery para fora do enquadramento.

## Roteiro

| Tempo | O que acontece | Fala / legenda |
|---|---|---|
| 0.0 s | Mamu de frente; a sacola de delivery ao lado do pé | |
| 0.5 s | Fala sério, olhando para a câmera | "Come comida de verdade." |
| 1.8 s | Sem mudar a expressão, o pé (ou a mão) empurra a sacola para fora do quadro | |
| 2.8 s | Olha para o outro lado e assobia (notas musicais) | |
| 3.6 s | Um barulho de embalagem fora do quadro. Ele trava | |

## Notas de animação

- O empurrão é lento e "discreto", com o corpo imóvel. A graça está no contraste.
