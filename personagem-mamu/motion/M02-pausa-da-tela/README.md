# M02: Faz uma pausa da tela

| | |
|---|---|
| **Status** | Ideia |
| **Gatilho no app** | Tempo de tela acima da meta |
| **Duração** | ~5 s |
| **Loop** | não |
| **Poses** | 1 (frente) + celular (a desenhar), da [folha v2](../../arte/mamu-v2.png) |

## Ideia em uma frase

Ele pede para você largar o celular enquanto segura o próprio celular.

## Roteiro

| Tempo | O que acontece | Fala / legenda |
|---|---|---|
| 0.0 s | Mamu olhando para o celular, rosto iluminado pela tela | |
| 0.8 s | Levanta os olhos, sem levantar a cabeça | "Faz uma pausa da tela." |
| 2.2 s | Percebe o celular na própria mão: olho arregalado ("pego no flagra") | |
| 3.0 s | Esconde o celular atrás da barriga, devagar | |
| 4.0 s | Encara a câmera como se nada tivesse acontecido. O celular vibra atrás dele | |

## Notas de animação

- A luz da tela no rosto apaga no momento em que ele esconde o celular.
- A vibração escondida atrás da barriga é o arremate da piada.
