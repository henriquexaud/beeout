# M01: Segunda eu começo

| | |
|---|---|
| **Status** | Ideia |
| **Gatilho no app** | Usuário adia a meta ou marca "começo segunda" |
| **Duração** | ~5 s |
| **Loop** | não |
| **Poses e expressões** | "Segunda eu começo" (shrug), "Side-eye sarcástico" |

## Ideia em uma frase

Ao ouvir "segunda", ele reconhece a frase: usou essa desculpa por algumas eras geológicas.

## Roteiro

| Tempo | O que acontece | Fala / legenda |
|---|---|---|
| 0.0 s | Idle. A palavra "segunda" aparece na tela | |
| 0.6 s | A orelha levanta antes do rosto. Side-eye lento para a palavra | |
| 1.4 s | Corte rápido: camadas de rocha (eras geológicas) com folhinhas de calendário "SEGUNDA" fossilizadas em cada camada | |
| 2.8 s | Volta. Shrug com o sorriso torto | "Conheço essa frase. Usei por algumas eras geológicas." |
| 4.4 s | Pausa, olhar para a câmera | |

## Notas de animação

- O corte das camadas de rocha pode ser um scroll vertical rápido, como se a câmera escavasse.
- O shrug tem antecipação curta e um settle pesado: os braços caem de volta e a barriga balança.
